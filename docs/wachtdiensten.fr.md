# Gardes

Les navires arrivent aussi la nuit et le week-end. Par site, quelqu'un est toujours **de garde** : un tour de garde 24/7, à l'heure du site.

## Ouvrir l'écran

Cliquez sur **Gardes** dans le menu de gauche et choisissez le site. En haut figure qui est de garde en ce moment. La consultation demande le droit de consulter le planning ; la modification, le droit de planifier.

## Générer le planning de garde

1. Cliquez sur **Générer le planning de garde**.
2. Choisissez dans **Experts, dans l'ordre** les experts dans l'ordre du tour.
3. Choisissez la **Première relève** (par exemple lundi 08:00), les **Jours par créneau** (7 pour une semaine) et le **Nombre de créneaux**.
4. Laissez **Remplacer les créneaux existants sur cette période** coché pour écraser un ancien planning. Un créneau qui dépasse la limite du nouveau planning est conservé ; Quaymark signale alors le chevauchement.

Chaque créneau commence là où le précédent se termine. Au passage à l'heure d'été ou d'hiver, la relève reste à la même heure.

## Modifier les créneaux

- **Nouveau créneau** ajoute un créneau (expert, de, à, remarque).
- Double-cliquez sur un créneau pour le modifier, par exemple pour l'échanger avec un collègue, ou pour le supprimer.

## Alertes

Pour les quatre prochaines semaines, Quaymark signale :

- un **trou** : une période sans garde ;
- un expert de garde **absent** (congé, maladie, formation) l'un des jours de son créneau ; → [Planning](planning.md)
- **deux gardes en même temps**, souvent une erreur de saisie.

L'écran d'accueil indique par site qui est de garde et combien d'alertes compte le planning. Le planning montre les créneaux de garde dans la colonne de l'expert ; ils n'y sont pas déplaçables.
