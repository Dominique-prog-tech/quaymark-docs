# Quaymark Dokumentation

Das Handbuch für Quaymark, die Plattform für maritime Besichtigungsbüros. Vom Auftrag bis zum herausgegebenen Bericht:
Akten, Feststellungen vor Ort mit Beweiskraft, Schreiben, Bescheinigungen und das Beweispaket.

</div>

!!! info "Das Handbuch folgt der App"
    Jede Seite beschreibt, was Sie in Quaymark auf dem Bildschirm sehen, auf Niederländisch, Französisch, Englisch und Deutsch.
    Suchen Sie eher eine Aufgabe als einen Bildschirm? Beginnen Sie mit **Wie mache ich…?**.
