# Unterschreiben lassen

An Bord lassen Sie den Kapitän, den Ersten Offizier oder das Terminal eine Erklärung unterschreiben, mit den Feststellungen dieses Moments. Verweigert er, halten Sie die Verweigerung mit dem Grund fest. Das funktioniert auch offline.

## Unterschreiben lassen

Tippen Sie auf **Unterschreiben** auf der Karte **Unterschriften** der Akte.

![Der Bildschirm Unterschreiben lassen: Name des Unterzeichners Capt. R. Lindqvist, die Funktion, Im Namen der Partei (optional), die Klausel, die Erklärung auf Englisch mit den vier Feststellungen, Verweigert die Unterschrift ausgeschaltet, und unter Unten unterschreiben eine Unterschrift.](../images/app-tekenen-de.png "Unterschreiben lassen"){ width="320" }

1. Geben Sie unter **Name des Unterzeichners** seinen Namen ein und wählen Sie seine **Funktion**.
2. Wählen Sie bei Bedarf **Im Namen der Partei (optional)**: eine der Parteien der Akte.
3. Wählen Sie die **Klausel**. Darunter steht die Erklärung mit den Feststellungen, die er unterschreibt.
4. Lassen Sie unter **Unten unterschreiben** unterschreiben. **Neu unterschreiben** leert das Feld.
5. Tippen Sie auf **Unterschrift speichern**.

Was der Unterzeichner liest, steht in der **Sprache der Akte**: die Erklärung, der Titel über den Feststellungen und die Orte an Bord. So unterschreibt ein englischsprachiger Kapitän eine englische Erklärung, auch wenn Ihre App auf Deutsch steht.

Solange ein Finger auf dem Unterschriftsfeld liegt, scrollt die Seite nicht mit.

## Verweigert er die Unterschrift

1. Schalten Sie **Verweigert die Unterschrift** ein.
2. Geben Sie den **Grund der Verweigerung** ein.
3. Tippen Sie auf **Verweigerung speichern**.

Auf der Karte steht die Verweigerung mit einem Verbotszeichen und dem Grund.

## Was Quaymark aufbewahrt

Eine Unterschrift wird nur **hinzugefügt**, nie geändert. Quaymark bewahrt die Erklärung und die Liste der Feststellungen zum Zeitpunkt der Unterschrift auf (die Momentaufnahme), das Bild der Unterschrift mit der Uhrzeit und, wenn das Gerät sie kennt, die Position. Ohne Position wird die Unterschrift trotzdem gesendet.

Eine Feststellung, die Sie nach der Unterschrift hinzufügen, steht nicht in dieser Unterschrift. Lassen Sie bei Bedarf erneut unterschreiben.

Offline wird die Unterschrift später gesendet, nach den Feststellungen, die darin stehen. Im Büro steht sie in der Registerkarte **Unterschriften** der Akte. → [Unterschriften](../dossiers.md#unterschriften)

## Häufige Fehler

!!! warning "Speichern klappt nicht"
    Die App verlangt einen Namen und eine Unterschrift im Feld. Bei einer Verweigerung verlangt sie einen Grund.
