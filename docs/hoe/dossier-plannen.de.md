# Wie plane ich eine Akte ein?

1. **Öffnen Sie die Planung** mit **Planung** im Menü und wählen Sie den Tag oder die Woche. → [Bildschirm öffnen](../planning.md#bildschirm-offnen)
2. **Suchen Sie die Akte** links unter **Zu planen**. Steht sie dort nicht, hat sie bereits einen Sachverständigen und einen Zeitpunkt. → [Zu planen](../planning.md#zu-planen)
3. **Ziehen Sie sie** auf die Spalte des Sachverständigen und die Uhrzeit, zu der die Arbeit beginnt. Eine Akte mit Status Neu wird Geplant. → [Eine Akte einplanen](../planning.md#eine-akte-einplanen)
4. **Ziehen Sie den Block länger**, wenn die Arbeit länger als zwei Stunden dauert. → [Verschieben und das Ende](../planning.md#verschieben-und-das-ende)
5. **Wird der Block rot?** Lesen Sie warum: eine Abwesenheit, ein Feiertag oder eine andere Akte zur selben Zeit. Die Akte ist trotzdem eingeplant. → [Warnungen](../planning.md#warnungen)

Siehe auch: [Wie lege ich eine neue Akte an?](nieuw-dossier.md)
