# Comment placer un formulaire de demande sur notre site web ?

1. **Demandez à ADM-Concept une clé de site web** pour votre bureau. Si vous avez plusieurs formulaires (par exemple une page de campagne), demandez une clé par formulaire : vous voyez ainsi pour chaque demande de quel formulaire elle vient.
2. **Transmettez la clé à votre webdesigner**, avec l'explication technique sur <https://platform.digitalcloud.be/docs/leads-contactformulier>.
3. **Donnez aux champs les noms reconnus**, pour que Quaymark complète lui-même le navire, le port, le type d'expertise et la date souhaitée. → [Formulaire web](../aanvragen.md#formulaire-web)
4. **Testez le formulaire** : remplissez-le vous-même. Une demi-minute plus tard, la demande figure sous **Demandes**, avec le badge **Site web** et une notification sur la cloche.
5. **Acceptez ou refusez** la demande. En l'acceptant, vous choisissez le donneur d'ordre ou vous en créez un à partir des données du demandeur. → [Demande](../aanvragen.md#demande)
