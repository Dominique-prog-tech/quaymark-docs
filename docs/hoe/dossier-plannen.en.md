# How do I schedule a file?

1. **Open the schedule** with **Schedule** in the menu and choose the day or the week. → [Opening the screen](../planning.md#opening-the-screen)
2. **Find the file** on the left under **To schedule**. If it is not there, it already has a surveyor and a time. → [To schedule](../planning.md#to-schedule)
3. **Drag it** onto the surveyor's column and the hour at which the work starts. A file with status New becomes Scheduled. → [Scheduling a file](../planning.md#scheduling-a-file)
4. **Stretch the block** if the work takes longer than two hours. → [Moving and the end time](../planning.md#moving-and-the-end-time)
5. **Does the block turn red?** Read why: an absence, a public holiday or another file at the same time. The file is scheduled all the same. → [Warnings](../planning.md#warnings)

See also: [How do I create a new file?](nieuw-dossier.md)
