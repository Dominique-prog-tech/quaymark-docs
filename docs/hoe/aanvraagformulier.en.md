# How do I put a request form on our website?

1. **Ask ADM-Concept for a website key** for your office. If you have more than one form (for example a campaign page), ask for a key per form: you then see for each request which form it came from.
2. **Give the key to your web developer**, with the technical explanation at <https://platform.digitalcloud.be/docs/leads-contactformulier>.
3. **Give the fields the recognised names**, so that Quaymark fills in the vessel, port, survey type and preferred date itself. → [Web form](../aanvragen.md#web-form)
4. **Test the form**: fill it in yourself. Half a minute later the request appears under **Requests**, with the **Website** badge and a notification on the bell.
5. **Accept or decline** the request. When accepting, you choose the principal or create one from the requester's details. → [Request](../aanvragen.md#request)
