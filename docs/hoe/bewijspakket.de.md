# Wie stelle ich ein Beweispaket für einen Schadensfall zusammen?

1. **Geben Sie zuerst den Bericht heraus.** Das Paket enthält die herausgegebenen Berichte, Schreiben und Bescheinigungen, keine Vorschauen. → [Bericht herausgeben und senden](../dossiers.md#bericht-herausgeben-und-senden)
2. **Klicken Sie in der Akte auf Beweispaket (ZIP).** Quaymark prüft beim Packen jede Datei nach; stimmt eine nicht mehr, entsteht kein Paket. → [Beweispaket](../dossiers.md#beweispaket)
3. **Stellen Sie das ZIP zu:** dem Anwalt, dem Versicherer oder dem Sachverständigen der Gegenpartei. Auch die Fotos, die Sie aus dem Bericht genommen haben, sind dabei, mit dem Grund. → [Fotos im Bericht](../dossiers.md#fotos-im-bericht)
4. **Der Empfänger prüft es nach** mit den Befehlen in der LIESMICH des Pakets, ohne Quaymark.
5. **Der Fingerabdruck des Pakets** steht danach auf der Registerkarte und im Journal: so zeigen Sie später, welches Paket Sie zugestellt haben.
