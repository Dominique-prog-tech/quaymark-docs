# How do I put together an evidence package for a claim?

1. **Issue the report first.** The package contains the issued reports, letters and certificates, not previews. → [Issuing and sending the report](../dossiers.md#issuing-and-sending-the-report)
2. **In the file, click Evidence package (ZIP).** Quaymark re-checks every file while packing; if a single one no longer matches, there is no package. → [Evidence package](../dossiers.md#evidence-package)
3. **Deliver the ZIP** to the lawyer, the insurer or the other party's surveyor. The photos you left out of the report are included too, with the reason. → [Photos in the report](../dossiers.md#photos-in-the-report)
4. **The recipient verifies it** with the commands in the package's README, without Quaymark.
5. **The package's fingerprint** then appears on the tab and in the journal: that way you can later show which package you delivered.
