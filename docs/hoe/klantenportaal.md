# Hoe geef ik een opdrachtgever toegang tot het klantenportaal?

1. **Open de relatie**: klik op **Relaties** en dubbelklik op de opdrachtgever. → [Relatie](../relaties.md#relatie)
2. **Staat de persoon er nog niet bij**, voeg die dan toe op het tabblad **Contactpersonen**, met een e-mailadres.
3. **Open het tabblad Klantenportaal**, kies de contactpersoon en klik op **Uitnodigen**. → [Klantenportaal](../relaties.md#klantenportaal)
4. **De contactpersoon kiest een wachtwoord** met de link uit de mail (7 dagen geldig) en stelt bij de eerste aanmelding tweestapsverificatie in. De status wordt dan *Actief*.
5. **Moet de toegang stoppen?** Klik op **Toegang intrekken**.

Wat de contactpersoon in het portaal ziet, staat op de pagina Relaties. → [Klantenportaal](../relaties.md#klantenportaal)
