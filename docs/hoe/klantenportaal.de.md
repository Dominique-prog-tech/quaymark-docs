# Wie gebe ich einem Auftraggeber Zugang zum Kundenportal?

1. **Öffnen Sie die Beziehung**: Klicken Sie auf **Beziehungen** und doppelklicken Sie auf den Auftraggeber. → [Beziehung](../relaties.md#beziehung)
2. **Steht die Person noch nicht dabei**, fügen Sie sie auf der Registerkarte **Ansprechpartner** hinzu, mit einer E-Mail-Adresse.
3. **Öffnen Sie die Registerkarte Kundenportal**, wählen Sie die Kontaktperson und klicken Sie auf **Einladen**. → [Kundenportal](../relaties.md#kundenportal)
4. **Die Kontaktperson wählt ein Passwort** mit dem Link aus der E-Mail (7 Tage gültig) und richtet bei der ersten Anmeldung die Zwei-Faktor-Authentifizierung ein. Der Status wird dann *Aktiv*.
5. **Soll der Zugang enden?** Klicken Sie auf **Zugang entziehen**.

Was die Kontaktperson im Portal sieht, steht auf der Seite Beziehungen. → [Kundenportal](../relaties.md#kundenportal)
