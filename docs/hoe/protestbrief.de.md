# Wie erstelle ich ein Protestschreiben?

1. **Öffnen Sie die Akte** und klicken Sie auf der Registerkarte **Bericht** auf **Neues Schreiben**. → [Schreiben und Bescheinigungen](../dossiers.md#schreiben-und-bescheinigungen)
2. **Wählen Sie unter Art das Protestschreiben** und unter **An** den Empfänger. Der Betreff ist bereits mit Schiff und Hafen ausgefüllt.
3. **Passen Sie den Text an.** Ersetzen Sie jedes Feld in [eckigen Klammern]: solange eines übrig ist, kann das Schreiben nicht herausgegeben werden.
4. **Prüfen Sie das Schreiben** mit **Vorschau (PDF)**.
5. **Klicken Sie auf Herausgeben.** Das Schreiben wird mit seinem Fingerabdruck festgeschrieben und kommt ins Beweispaket. → [Beweispaket](../dossiers.md#beweispaket)

Das Layout des Schreibens kommt aus seiner Vorlage. → [Vorlagen](../sjablonen.md#die-liste)
