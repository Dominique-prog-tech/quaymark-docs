# Wie stelle ich ein Anfrageformular auf unsere Website?

1. **Fragen Sie ADM-Concept nach einem Website-Schlüssel** für Ihr Büro. Haben Sie mehr als ein Formular (zum Beispiel eine Kampagnenseite), fragen Sie nach einem Schlüssel pro Formular: So sehen Sie bei jeder Anfrage, von welchem Formular sie kam.
2. **Geben Sie den Schlüssel Ihrem Webentwickler**, mit der technischen Erklärung unter <https://platform.digitalcloud.be/docs/leads-contactformulier>.
3. **Geben Sie den Feldern die erkannten Namen**, damit Quaymark Schiff, Hafen, Besichtigungsart und Wunschtermin selbst ausfüllt. → [Webformular](../aanvragen.md#webformular)
4. **Testen Sie das Formular**: Füllen Sie es selbst aus. Eine halbe Minute später steht die Anfrage unter **Anfragen**, mit dem Abzeichen **Website** und einer Meldung an der Glocke.
5. **Nehmen Sie die Anfrage an oder lehnen Sie sie ab**. Beim Annehmen wählen Sie den Auftraggeber oder legen einen aus den Daten des Anfragenden an. → [Anfrage](../aanvragen.md#anfrage)
