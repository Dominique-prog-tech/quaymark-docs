# Wie setze ich unser Logo in den Bericht?

1. **Öffnen Sie die Vorlagen** mit **Einstellungen** und **Vorlagen**, und öffnen Sie die **allgemeine** Vorlage. Sie gilt für jede Besichtigungsart. → [Die Liste](../sjablonen.md#die-liste)
2. **Wählen Sie die Registerkarte einer Sprache** und klicken Sie auf **Dokument bearbeiten**. → [Berichtsvorlage](../sjablonen.md#berichtsvorlage)
3. **Fügen Sie Ihr Logo und Ihr Erscheinungsbild** in das Word-Dokument ein, und speichern Sie mit **Als neue Version speichern**.
4. **Wiederholen Sie das für jede Sprache**, in der Sie berichten. Die Spalte **Dokumente** zeigt pro Sprache die aktuelle Version.
5. **Prüfen Sie das Ergebnis** in einer Akte mit **Bericht (PDF)**. → [Berichtsvorschau](../dossiers.md#berichtsvorschau)

Eine Vorlage für eine einzige Besichtigungsart hat Vorrang vor der allgemeinen: setzen Sie das Logo auch dort ein.
