# Comment comparer un off-hire à l'on-hire ?

1. **Ouvrez le dossier on-hire et cliquez sur Copier.** Le nouveau dossier reprend la même mission et est lié à l'on-hire. → [Copier](../dossiers.md#copier)
2. **Le dossier off-hire existe déjà ?** Choisissez alors sous **Dossier lié** le dossier on-hire du même navire. → [Dossier](../dossiers.md#dossier)
3. **Sur place,** l'expert enregistre les constatations de l'off-hire dans l'application mobile. → [Constatations](../dossiers.md#constatations)
4. **Donnez votre appréciation par constatation** dans l'onglet **Constatations** : **Existait déjà** ou **Nouveau**. L'onglet montre par emplacement ce que l'on-hire y a constaté. → [Comparaison avec un dossier précédent](../dossiers.md#comparaison-avec-un-dossier-precedent)
5. **Émettez le rapport.** Il montre la comparaison par emplacement à bord, avec les numéros de photo et votre appréciation. → [Émettre et envoyer le rapport](../dossiers.md#emettre-et-envoyer-le-rapport)
6. **Besoin d'un certificat ?** Établissez le certificat on-hire/off-hire avec **Nouveau certificat**. → [Lettres et certificats](../dossiers.md#lettres-et-certificats)
