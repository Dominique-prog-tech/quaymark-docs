# How do I compare an off-hire with the on-hire?

1. **Open the on-hire file and click Copy.** The new file gets the same instruction and is linked to the on-hire. → [Copy](../dossiers.md#copy)
2. **Does the off-hire file already exist?** Then choose the on-hire file of the same vessel under **Linked file**. → [File](../dossiers.md#file)
3. **On site,** the surveyor records the off-hire findings in the field app. → [Findings](../dossiers.md#findings)
4. **Give your assessment per finding** on the **Findings** tab: **Already existed** or **New**. The tab shows per location what the on-hire found there. → [Comparison with a previous file](../dossiers.md#comparison-with-a-previous-file)
5. **Issue the report.** It shows the comparison per location on board, with the photo numbers and your assessment. → [Issuing and sending the report](../dossiers.md#issuing-and-sending-the-report)
6. **Need a certificate?** Create the on-hire/off-hire certificate with **New certificate**. → [Letters and certificates](../dossiers.md#letters-and-certificates)
