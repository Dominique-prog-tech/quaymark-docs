# Comment émettre un rapport et le remettre au donneur d'ordre ?

1. **Mettez le dossier au statut Rapport.** Dès lors, les champs obligatoires de l'expertise doivent être remplis. → [Dossier](../dossiers.md#dossier)
2. **Rédigez les rubriques** dans l'onglet **Rapport**, avec les textes types de votre bureau ou un **projet** proposé par l'IA, et cliquez sur **Enregistrer les rubriques**. → [Rapport](../dossiers.md#rapport) · [Proposer un projet](../dossiers.md#proposer-un-projet)
3. **Relisez le rapport** avec **Rapport (PDF)**. Rien n'est encore enregistré ni envoyé. → [Aperçu du rapport](../dossiers.md#apercu-du-rapport)
4. **Cliquez sur Émettre le rapport.** Le rapport devient la version 1, avec son empreinte, et ne change plus ensuite. → [Émettre et envoyer le rapport](../dossiers.md#emettre-et-envoyer-le-rapport)
5. **Cliquez sur Envoyer.** Le donneur d'ordre reçoit le PDF ; le mail est consigné dans le journal du dossier.
6. **Faut-il corriger quelque chose ?** Utilisez **Émettre une nouvelle version** et indiquez une raison. La version précédente reste conservée.
