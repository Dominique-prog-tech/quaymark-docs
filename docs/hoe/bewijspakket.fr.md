# Comment constituer un dossier de preuves pour une réclamation ?

1. **Émettez d'abord le rapport.** Le dossier de preuves contient les rapports, lettres et certificats émis, pas les aperçus. → [Émettre et envoyer le rapport](../dossiers.md#emettre-et-envoyer-le-rapport)
2. **Dans le dossier, cliquez sur Dossier de preuves (ZIP).** Quaymark revérifie chaque fichier lors de l'emballage ; si un seul ne correspond plus, il n'y a pas de dossier de preuves. → [Dossier de preuves](../dossiers.md#dossier-de-preuves)
3. **Remettez le ZIP** à l'avocat, à l'assureur ou à l'expert de la partie adverse. Les photos que vous avez retirées du rapport s'y trouvent aussi, avec la raison. → [Photos dans le rapport](../dossiers.md#photos-dans-le-rapport)
4. **Le destinataire le vérifie** avec les commandes du LISEZMOI, sans Quaymark.
5. **L'empreinte du dossier de preuves** figure ensuite dans l'onglet et dans le journal : vous pourrez ainsi montrer plus tard quel paquet vous avez remis.
