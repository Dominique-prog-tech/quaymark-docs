# Mon travail

La page d'un **expert freelance**. Avec le rôle Freelance, c'est le seul écran que vous voyez dans l'application web : vos dossiers, votre temps, vos frais et vos décomptes. Le travail sur place se fait dans l'application de terrain. → [Freelances](freelancers.md#le-role-freelance)

## Ouvrir l'écran

Connectez-vous : Quaymark ouvre directement **Mon travail**. Dans le menu, il figure sous **Mon travail**.

## Mes dossiers

Les dossiers qui vous sont attribués, avec leur statut sous forme d'étiquette colorée (bleu ce qui reste à faire, orange ce qui est en cours, vert ce qui est terminé), l'heure prévue et le port. Vous les ouvrez dans l'application de terrain.

## Mon temps

Vous enregistrez votre temps dans l'application de terrain, sur le dossier. Ici, vous voyez tout ce que vous avez enregistré, avec les heures. Ce qui figure sur un décompte porte la mention *Réglé*.

## Mes frais

Cliquez sur **Ajouter un frais** pour un frais que vous avez payé vous-même (un trajet, un parking, une nuitée) :

- **Dossier** : un dossier qui vous est attribué.
- **Date**, **Type**, **Description** et **Montant**.
- **Ticket** : une photo ou un PDF, 15 Mo au plus. Il rejoint les pièces jointes du dossier, pour que le bureau le voie.

Un frais qui n'est pas encore réglé ni facturé peut être supprimé avec **⋯** en fin de ligne. Ensuite, il est figé. Chaque liste a un champ de recherche, et **Exporter** l'emporte vers Excel.

Si le bureau n'a pas encore créé votre fiche de freelance, la page vous le dit. Vous pouvez déjà saisir des frais ; le décompte n'est possible qu'avec une fiche.

## Mes décomptes

Les décomptes que le bureau a émis pour vous (autofacturation), avec numéro, date, période et total. Cliquez sur **PDF** pour les ouvrir.
